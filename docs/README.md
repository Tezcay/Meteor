- **针对你已补充的基础，实际执行优先看 [一月冲刺学习计划](07-一月冲刺学习计划.md)**：Java 后端方向，已有面向对象及 Spring Boot／MyBatis 基础；按有效学习时间调整。
- 开始学习后看 [学习执行日志](08-学习执行日志.md)：记录实际环境、每日任务、掌握状态和下一步；计划与实际进度分开维护。
- 再按 [技术知识地图与项目学习路线](06-技术知识地图与项目学习路线.md) 的 M0 开始；资料按阶段查阅，不要求全部学完再做项目。
- 需要核对业务时再查下面的设计文档。学习建议中的工具选择尚不是已安装、已验证的依赖清单。

学习执行顺序以最新学习路线为准；业务含义和 C1／C2 验收以下面的 V0.3.0 设计为准。尤其是“小验证后完善详细设计”，不表示验证前无需最小表结构、约束和接口契约。

## 版本约定

本项目设计文档采用自定义的三段版本约定，借鉴 SemVer 的写法，不声称对尚未形成的公共 API 作兼容性保证：

- `0.2.1`：修正错字、链接或不改变既定业务含义的澄清。
- `0.3.0`：新增设计内容，或调整范围、模型、状态等实质规则。
- `1.0.0`：核心需求和详细设计经评审形成首个开发基线，不代表软件已上线。

V0.1 视为历史的 0.1.0 简写；V0.2.0 增加领域模型、状态机、时序与交付分层；V0.3.0 调整数据库默认值与求职学习范围。后续软件版本、商品发布版本分别管理。

参考：[语义化版本规范](https://semver.org/lang/zh-CN/)。正式 SemVer 面向公共 API，不能直接把上述文档约定称为其强制规则。
