# Meteor 历史文档归档

这里保存已经被当前设计或学习路线替代的文档。文件没有删除，仍可用于追溯需求演化；日常开发、学习和面试准备请从 [当前文档导航](../README.md) 开始。

## 为什么归档

- 同一主题曾有 V0.1、V0.2.0、V0.3.x 和 V0.4.0，多版本平铺容易误读旧规则。
- 早期学习计划写于代码实现之前，其中“尚未开始”等状态已经失效。
- 旧视觉稿对应早期页面方向，不能作为当前 Vue 页面验收依据。

## 使用规则

1. 归档文件中的“下一步”“当前状态”和技术选型只代表当时，不覆盖主目录文档。
2. 如果旧文档中的某项规则仍然重要，应把它重新写入当前 V0.4.0 文档或新 ADR，不能只引用归档文件。
3. 新版本替代旧版本时，先更新当前导航和相对链接，再把旧文件移动到本目录。
4. 归档不是删除；需要研究演进过程时可以按 V0.1 → V0.2.0 → V0.3.x → V0.4.0 阅读。
